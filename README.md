# text_sign.py

テキストへの Ed25519 署名を作成・検証する、小さな Python ツールです。

任意のテキスト（UUID、名前、フレーズ、URL など）に対して秘密鍵で署名し、Base64 形式の署名を生成します。対応する公開鍵を事前に公開しておけば、誰でも「テキスト＋署名＋公開鍵」で検証して、「そのテキストが鍵の持ち主によって署名されたものだ」と確認できます。

写真や文書などに署名を添えておくことで、出所の証明に使うことを想定しています。

## 特徴

- 機能は3つだけ：鍵ペアの生成（`keygen`）、署名（`sign`）、検証（`verify`）
- 署名には Ed25519 を使用。秘密鍵はパスフレーズで暗号化して保存されます
- 署名は常に Base64 で 88 文字固定（テキストの長さによらず一定）
- Ed25519 の署名は決定的（deterministic）なため、同じ鍵・同じテキストからは常に同じ署名が得られます
- 依存ライブラリは `cryptography` のみ

## 仕組み

署名は、テキストと秘密鍵から計算される 64 バイトのデータで、Base64 にすると 88 文字になります。

```
署名 = Base64( Ed25519署名(64バイト) )
```

署名は「印鑑の印影」のようなもので、そのテキストと秘密鍵の組み合わせでしか作れず、テキストが1文字でも変われば合わなくなります。一方で、署名そのものにテキストの内容は含まれていません。

そのため検証は、**テキスト・署名・公開鍵の3点をそろえて**、署名がそのテキストに対して正しく作られたものかを計算で確かめる、という手順になります。検証が成功すれば、「そのテキストは、公開鍵に対応する秘密鍵の持ち主が署名したものであり、署名後に書き換えられていない」ことが分かります。

なお、暗号技術が証明するのは「署名が、公開鍵に対応する秘密鍵で作成されたこと」までです。「その鍵が誰のものか」という結び付けは、公開鍵を事前に公開した記録（日時つきの投稿など）が担います。詳しくは「セキュリティ上の注意」を参照してください。

## 動作環境

- Python 3.9 以降
- ライブラリ：`cryptography`

```bash
pip install cryptography
```

## 使い方

### 1. 鍵ペアを生成する（初回のみ）

```bash
python text_sign.py keygen
```

秘密鍵のパスフレーズ（8文字以上）を決めて2回入力すると、スクリプトと同じフォルダに以下のファイルが生成されます。

| ファイル | 内容 |
| --- | --- |
| `private_key.pem` | 秘密鍵（パスフレーズで暗号化） |
| `public_key.txt` | 公開鍵（Base64） |
| `declaration.txt` | 公開鍵の宣言文面案 |

### 2. 公開鍵を事前に公開する

`declaration.txt` の文面（対象テキストと公開鍵を含む）を、ブログや SNS など日時の記録が残る場所に公開しておきます。これが「この公開鍵は自分のものだ」という証跡になります。

### 3. 署名を生成する

```bash
python text_sign.py sign
```

パスフレーズを入力すると、署名が表示され、`signature.txt` にも保存されます。

オプション：

```bash
# 任意のテキストに署名する
python text_sign.py sign --text "署名したい文字列"

# 秘密鍵ファイルを明示する
python text_sign.py sign --key /path/to/private_key.pem
```

既定の署名対象テキストは、スクリプト内の `DEFAULT_TEXT` で変更できます。

### 4. 検証する

```bash
python text_sign.py verify --sig <署名>
```

署名対象のテキストが既定値（`DEFAULT_TEXT`）と異なる場合は、`--text` で指定します。

```bash
python text_sign.py verify --text "署名された文字列" --sig <署名>
```

署名が正しければ「検証OK」、テキストや署名が改ざんされていれば「検証NG」と表示されます。公開鍵は同じフォルダの `public_key.txt` が自動で読み込まれます。別の環境で検証する場合は、公開鍵も一緒に指定してください。

```bash
python text_sign.py verify --text "署名された文字列" --sig <署名> --pub <公開鍵Base64>
```

## セキュリティ上の注意

- **秘密鍵とパスフレーズの管理がすべてです。** `private_key.pem` は他人に渡さず、必ずバックアップを取ってください。パスフレーズはスクリプトのどこにも保存されないため、忘れると秘密鍵が使えなくなります（その場合は鍵ペアを作り直し、宣言も新しい公開鍵で出し直す必要があります）。
- 秘密鍵ファイルが漏洩したり、パスフレーズが知られたりすると、第三者に署名を偽造される可能性があります。
- 検証が成功しても、それだけで「署名者が特定の本人である」ことまでは証明されません。証明されるのは「公開鍵に対応する秘密鍵の持ち主が署名したこと」です。本人との結び付けは、手順2の公開記録と合わせて判断してください。

## 制限事項

- テキストは UTF-8 として扱われます。日本語などのマルチバイト文字も署名できます。
